Ember — Design Reference

The canonical look for the build. Match these in React Native: palette, spacing, 1.5px strokes, rounded forms, the amber flame as the only colour accent, companions in ink-line style. Warm paper background, not white. This file is the source of truth referenced by the build prompts.

Radii: screen frame 30 · cards 14–16 · buttons pill 40
Strokes: 1.5px standard, 2.2–2.4px on companion outlines
Type: system sans, weight 500 for numbers/headings; uppercase + 1.5–2px letter-spacing for labels/buttons
Rule: everything monochrome except the flame. One accent, used sparingly.
